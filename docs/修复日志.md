  - **#5 构建口令脱敏与重连统计连续性**：移除 `android/app/build.gradle.kts` 中的硬编码签名口令字面量（改读环境变量 `MIPLAY_ACCEPTANCE_STORE_PASSWORD` / `MIPLAY_ACCEPTANCE_KEY_PASSWORD`）并新增契约单测 `buildGradle_doesNotContainHardcodedSigningPasswords`；`core/src/session.rs` `stats()` 合并 `pending` 重连退避队列（`phase="reconnecting"`），保持断线重连期间接收端统计连续可见。

    2. 消除首台建连窗口期丢点击：`CastService` 维护目标接收端集合与串行协调队列（`triggerReconcile`），首台 `NativeBridge.connect` 期间或授权返回间隙追加勾选的第二台音箱不再因 `session == None` 被丢弃，而是在首台就绪后自动补发 `addReceiver`。
    3. 中途加入 `connecting` 转圈展示、自动重试与取消隔离：`core/src/session.rs` 新增 `connecting` 状态合并（含独立取消令牌 `Arc<AtomicBool>` 隔离“连接途中取消又立即重勾”）、首次中途加入失败自动重试及 `pending` 退避接管；Android 侧点击音箱即刻注入 `connecting` 占位以显示加载转圈。
    4. 关键操作日志独立留存：`CastService` 新增 `OP_EVENT` 环形缓冲与 `files/cast_ops.log` 持久化（64KB 轮转），避免操作事件被 1Hz `STATS` 日志冲刷覆盖。

## 已落地修复条目（有证据）

### 1. 单机 / 多音箱 MiPlay 与 Legacy / Safety 认证路径（代码存在）

- **事实**：核心会话支持 `AuthMode::{Legacy, Safety, Auto}`（`core/src/session.rs`）；JNI `setAuthMode`（`core/src/ffi.rs`）；UI 认证选项经 `AuthModeResolve`（有 `AuthModeResolveTest`）。
- **证据提交**：功能贯穿基线与后续连接诊断提交（如 `57d5d0e`、`feb37b5`）；单测类 `AuthModeResolveTest` 计入 0.9.3 验收 JVM 套件。
- **测试范围**：JVM 认证解析单测；**真机全矩阵「Safety/Legacy × 单/多箱」通过情况：待核实**（仓库 docs 对 LX06 等明确「不宣称已修好」：`docs/LX06_V8_POSTMORTEM.md`）。
- **用户 0.9.3 华为可投送**：仅证明该机该包可投送路径可用，**不**自动覆盖所有认证组合与双箱听感。

### 2. CastService `localMute` 构造期崩溃（0.9.2）

- **现象（文档记录）**：小米 17 Pro、acceptance 0.9.1（versionCode 10），MediaProjection 授权后 `CastService` 启动 NPE（`getApplicationContext` 于未 attach 的 Service）。
- **修法**：`lateinit localMute`，`onCreate` 后用已附加 Context 构建；`AndroidStreamMusicVolume` 注入 `AudioManager`。
- **证据**：提交 `870e4a6`；文档 `docs/CASTSERVICE_MUTE_INIT_CRASH.md`；回归 `CastServiceMuteInitTest`。
- **版本**：versionCode **11** / `0.9.2-cast-panel`（acceptance 后缀由 flavor）。
- **测试范围**：JVM 构造路径回归；真机是否复测 0.9.2：**待核实**（后续用户确认的是 **0.9.3**）。

### 3. minSdk 29 真实兼容（0.9.3，非仅改数字）

- **代码入口**：`compat/BlurCompat` + `BlurEffectApi31`；`WindowInsetsApplyCompat`；`NotificationPermissionCompat`；`PackageSigningCompat`；`CaptureSelectionLayers`；`AcceptanceAudioDefaults`；`LocalOutputMute` 增加 `UNVERIFIED_NO_CAPTURE_ENERGY`；`scripts/build-debug.sh` 使用 `cargo ndk -p 29`；报告 `docs/API29_COMPAT_REPORT.md`。

### 4. MediaProjection 授权框 vs App UID 两层选择澄清

- **证据**：`LocalOutputMute.kt`（`60f54ee`）；`LocalOutputMuteUnverifiedTest`；`docs/LOCAL_MUTE.md`。
- **测试范围**：JVM；真机探针行为：**未在本日志宣称通过**。
