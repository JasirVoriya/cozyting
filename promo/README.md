# 妙投（MiaoCast）产品宣传片工程（Remotion · 全实机 UI 联动版）

本目录包含 **妙投（MiaoCast）** 的 66 秒 1080p 60fps 纯视觉产品宣传视频源码。全片**零旁白、零人声说教**，以仓库内 16 张真实双主题高清实机渲染截图为绝对视觉主角，结合 **2.5D 真实卡片无损切片悬浮（`<UiSlice>` / `<StagePhone>`）**、**拟真触控与界面流转**、**120 BPM 原创程序化合成音乐**以及**从真实 UI 卡片生长延伸出的声学/空间动态图形**，直观传递项目的核心能力。

## 2. 构建与渲染

依赖环境：Node.js 20+、`ffmpeg`。

```bash
# 1. 安装依赖
npm install

# 2. 程序化合成 48kHz 立体声无旁白配乐（输出至 public/music.wav）
npm run music

# 3. 从 ../docs/assets/screenshots/ 裁切深/浅色实机界面素材（输出至 public/ui/）
npm run assets

# 4. 启动交互式预览（可选）
npm run studio

# 5. 渲染 1080p 60fps MP4（输出至 out/miaocast-promo.mp4）
npm run render
```
