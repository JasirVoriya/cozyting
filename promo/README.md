# 妙投（MiaoCast）产品宣传片工程（Remotion · 用户视角实机联动版）

本目录包含 **妙投（MiaoCast）** 的 62 秒 1080p 60fps 纯视觉产品宣传视频源码。全片**零旁白、零人声说教**，站在真实使用者视角，以高对比大字排版、核心功能 UI 强聚焦特写（`<UiSlice>` / `<StagePhone>`）、真实生活场景对照与 120 BPM 原创程序化合成音乐，直观传递项目的核心能力。

## 2. 构建与渲染

依赖环境：Node.js 20+、`ffmpeg`。

```bash
# 1. 安装依赖
npm install

# 2. 程序化合成 48kHz 立体声无旁白配乐（62 秒，输出至 public/music.wav）
npm run music

# 3. 从 ../docs/assets/screenshots/ 裁切深/浅色实机界面素材（输出至 public/ui/）
npm run assets

# 4. 启动交互式预览（可选）
npm run studio

# 5. 渲染 1080p 60fps MP4（输出至 out/miaocast-promo.mp4）
npm run render
```
